### 1-4. 오는 길에 바로잡은 것

- **커리큘럼 이탈**: 처음에 A2를 건너뛰고 DeepSeek-V4로 바로 감. "한 단계에 부품 하나" 원칙을 "모델 단위 구현 + 스위치 단위 실험"으로 수정.
- **틀린 설명**: A4를 "MLA"로 적었으나 V4는 K=V 단일 head + 시퀀스 방향 KV 압축. 최신 모델 정보는 웹 검색으로 재확인.
- **빠진 모델**: Qwen 플래그십(2.4T), StepFun Step-5, Gemma 4 추가. C2를 Qwen-Image-2.1로 교체.
- **검증 공백**: 순전파만 검증하고 학습은 확인하지 않았음 → 학습 동작 검증·학습 코드 검증을 추가.
- **검증 코드 버그**: pip `>=` 셸 리다이렉트, 체크포인트 RNG 상태 GPU 로딩, closure 로 감싼 원본의 deepcopy, 내부 fp32 고정 모델에 float64 수치 미분, 도달 불가능한 난수 목표 등.
- **태스크 설계 결함**: MQAR에서 모든 키를 한 번씩 물으면 소거법으로 정확도 0.34를 얻는 지름길이 생김 → 질문 중복 허용으로 수정. 이후 Llama가 16,500 step 정체 후 17,000~19,500 step에 0.16 → 0.91로 급상승 (induction 회로 형성).

### 1-5. 검증에서 알게 된 원본 쪽 특성

- **원본이 추론 전용인 모델**: A8(전체 no_grad), A6b(MoE가 eval 모드에서 no_grad). 이 모델들은 원본 대신 수치 미분으로 backward를 확인했습니다.
- **MoE 학습 궤적**: 1e-5 수준 차이로도 top-k 선택이 갈라져 궤적이 벌어집니다. 기울기 비교로 계산을 확인하고, 궤적 비교는 처음 3 step만 합니다.
- **의도된 stop-gradient**: indexer(DSA, MSA, Step-5)는 원본도 backbone으로 기울기를 보내지 않습니다.

## 3. 앞으로 할 것

### 4단계 · 부품별 실험 (LLM, MQAR부터)

같은 태스크·같은 측정·같은 크기에서 **스위치 하나만** 바꿔 비교합니다. 기록은 `runs/<태스크>/<모델>/<변형>/seed<k>`로 TensorBoard에 겹쳐 봅니다.

| 비교 | 보는 것 |
|---|---|
| A1 full attention vs A2 sliding (+sink) | 창 밖 키 회상이 창 크기에서 꺾이는가, sink 확률이 언제 오르는가 |
| DeepSeek-V4: sliding만 → +CSA/HCA → +MoE → +mHC | 압축 KV가 먼 회상을 얼마나 되살리는가, indexer가 정답 블록을 고르는가, mHC가 학습 안정성에 주는 영향 |
| Qwen3.6 선형:full 비율, Kimi KDA vs Gated DeltaNet | 고정 크기 메모리가 키 몇 개에서 무너지는가 |
| MoE on/off, 라우터 bias on/off | expert 쏠림, 학습 곡선 |
| 거리·키 개수 sweep | 각 부품의 한계 지점 |

순서
1. MQAR 실험 노트북: 모델·스위치·seed sweep, 거리별 정확도, MI 지표
2. MI 도구 보강: probe, activation patching (원래 2단계 계획에 있던 것)
3. 태스크 추가: 여러 자리 덧셈 → 미로 최단경로
4. 결과 정리: 부품별로 "무엇을 할 수 있게 해주는가"

### 5단계 · DiT · 멀티모달 실험

- DiT: FashionMNIST 조건부 생성 → 편집(가린 부분 채우기, 클래스 바꾸기) → Moving-MNIST. MM-DiT(B1) vs single-stream(B2, C2) 조건 주입 비교
- 멀티모달: FashionMNIST 이미지 질의응답(C0) → 이미지로 본 미로에서 행동 출력(C1)
